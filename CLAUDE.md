# CLAUDE.md — data-mapping-for-engineers

Course repository: lessons (markdown) + labs (.NET 8 / SQL) + an MCP capstone. The written lessons are the product; code exists to make lessons runnable.

## Hard rules
- **No employer or client references, ever.** Patterns are generalized; datasets are synthetic. If a lesson example starts to resemble a specific real engagement, generalize it further.
- **All code written fresh in this repo.** Do not port or adapt code from any other repository (including GPL-licensed forks elsewhere on this machine). MIT-licensed, original work only.
- **Synthetic data only**, generated by `data/` tooling with a fixed seed for reproducibility.
- Lessons are written in first person, plain prose, minimal bullets — teaching voice, not documentation voice. The author edits every lesson personally before commit.

## Project conventions
- .NET 8, C# latest stable. Projects: `DataMapping.Core` (profiling/mapping logic), `DataMapping.Mcp` (capstone MCP server, stdio transport), `DataMapping.Evals` (scored tool-call test harness).
- Labs reference `src/` code; each lab's `README.md` states its goal, steps, and "you're done when" criteria.
- ADRs in `docs/decisions/` for any non-obvious architectural choice.
